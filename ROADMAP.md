# Roadmap

Direction for BioKyn. Priorities follow community feedback; open an issue or discussion to propose changes.

## Now
- Stable 0.4 release line and 1.0 API freeze
- Public evaluation datasets and tooling for kinematic calibration
- More framework adapters (Fastify, Hono, Nest, Cloudflare Workers)

## Next
- Privacy Pass (RFC 9578) issuer/redemption interoperability
- Additional shared-store backends
- Expanded accessibility testing with assistive-technology users

## Later
- Hardware attestation options for the WebAuthn lane
- Managed key-rotation helpers and an admin dashboard example

## Always
Privacy first, accessible by default, free and open source.
