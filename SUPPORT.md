# Getting Help

If you have questions about BioKyn:

- **Documentation:** Check [biokyn.github.io](https://biokyn.github.io) for setup guides.
- **GitHub Discussions:** Use our [Discussions tab](https://github.com/biokyn/biokyn/discussions) for general questions.
- **Issues:** Use [GitHub Issues](https://github.com/biokyn/biokyn/issues) for confirmed bugs only.
- **Security:** Use the private [Security Policy](SECURITY.md) for vulnerability reports.
